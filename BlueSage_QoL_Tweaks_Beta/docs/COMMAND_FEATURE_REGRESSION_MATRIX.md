# BlueSage QoL Command And Feature Regression Matrix

This is a release contract, not optional documentation. `CommandInventoryContractTests` compares this inventory with `RegisterBlueSageCommands`; adding or removing a literal command without updating this map fails verification.

## Identity and style state

| Commands | Allowed mutation | Required invariant |
|---|---|---|
| `/setname` | Styled base name | Validate full composed length; preserve status/Spoons; native save and roster sync; `reset` restores current Steam persona name |
| `/status` (`/setstatus`, `/set-status`), `/brb`, `/afk`, `/back`, `/clearstatus` (`/clear-status`), `/statuscolor` | Status text/color only | Capture the exact styled base before mutation; never infer arbitrary bracketed name text; status-color `reset` restores `FFD45D` |
| `/spoons`, `/setmood` (`/spoonlabel`) | Spoons count/label/visibility only | Preserve exact base and status; invalid drafts cannot partially mutate saved state |
| `/style` (`/sty`), `/styleui` (`/sui`) | Explicit user-selected style draft/apply | Detect real live colors/tags; undo/redo restores the exact prior state |

Required transition fixture: styled `Rowan` + `(Reading)` + `[4/5sp]` → `/brb` → `/afk` → `/back` must restore `(Reading)`, while the styled base and Spoons suffix remain byte-for-byte unchanged at every step.

## Lobby, reconnect, and community

`/bsqol` (`/qol`, `/guide`, `/faq`), `/announce`, `/motd`, `/fishaid` (`/autofish`), `/hosthealth` (`/hh`), `/leavenotices` (`/ln`), `/reconnectguard` (`/rg`), `/reconnectmessage` (`/rm`), `/helper` (`/lobbyhelper`, `/lobbymod`, `/modhelper`, `/moderationhelper`), `/sidlist`, `/sidincident` (`/cloneincident`), `/sidwho` (`/sidlookup`), `/idsync status`, `/idsync refresh`, `/idsync repair`, `/idsync request`, `/identitysync`, `/rostersync`, `/sidban`, `/sidunban` (`/unbansid`), `/sidkick`, `/sidmute`, `/sidunmute`, `/communitybans` (`/communityban`, `/bansync`), `/qolmenu` (`/qm`).

Invariant: Reconnect Guard never rejoins instantly: it holds ReconnectRejoinHoldSeconds (default 20, clamped 10-120, menu-adjustable) on the clean menu first and cancels if the player leaves the clean menu during the hold; local status responses remain visible/copyable; reconnect requires authoritative Steam/PurrNet/player alignment; Helper authority uses one stable owner-scoped SteamID whitelist for `@lobby` and host-validated moderation requests. Legacy helper lists migrate only when their saved owner matches the current host. `/sidwho` is read-only and marks a row verified only when its exact SteamID64 and PlayerID are unique across the aligned native roster and current Steam lobby; names never select a moderation target. `/idsync status` is read-only and gives an ordinary QoL user safe coverage/evidence only. `/idsync refresh` performs a local-only native-surface refresh without server or lobby mutation. Legacy bare `/identitysync` and `/rostersync` are read-only aliases of `/idsync status`; they never select repair or request behavior from caller role. `/idsync repair` is a one-shot selective repair for the exact current Host. `/idsync request` is available to a freshly authenticated Helper/Mod only through Host relay and revalidation. Every identity-sync operation leaves already verified rows untouched, keeps ambiguous rows visible but locked, and cannot grant authority. Vanilla ID-card and moderation surfaces remain untouched. `/sidincident` resolves through the same controller as Lobby Safety; dismiss/clear actions are local-only and never mutate bans, Helpers, or lobby state. Only the host writes native ban state, and Helper requests are authenticated from the authoritative PurrNet sender before the incident suspect is re-resolved. Community Safety starts on for a fresh install and remains a per-client choice: any QoL client may validate the bounded current upstream source and append only missing pairs to its own local native ban store. A malformed source or persistence failure rolls back; refresh never kicks, bans, or grants authority. Status and the local attestation expose only enabled state, attempt/success time, HTTP result, revision/hash, accepted count, next attempt, and a bounded error—never player identities.

## Performance, movement, and local visuals

`/assetsweep` (`/as`), `/bettermove` (`/bm`), `/unlimitedconsumables` (`/consumables`, `/infiniteconsumables`), `/focusanywhere` (`/fa`), `/minimaplabels` (`/mml`), `/cloneshield` (`/cloneguard`, `/identityshield`), `/playersaver` (`/rendercull`, `/playercull`), `/selfmove` (`/bluemove`, `/qolmove`), `/rebind` (`/bind`, `/kb`, `/keys`), `/welcome` (`/howto`).

Invariant: toggles reflect actual runtime behavior; experimental performance claims require measurable counters and restoration proof. `/selfmove` and the menu operate the same self-only Save Pos, Teleport Saved, Noclip/Fly, speed, jump, gravity, and reset state; saved-position and rescue teleports request the owner's normal network transform sync. Reusable Consumables suppresses only the current canteen/chalk inventory decrement after an item is owned, and puts back the one owned bait vanilla spends when a bite starts the reel mini-game (never creates bait the player did not own). Turning it off restores vanilla decrement immediately; clothing, rods, bobbers, initial purchases, and the ticket wallet remain game-owned. Hosts publish a sanitized MOTD (`/motd` or the menu; default "Welcome to my server!") in owner-only lobby data; QoL players show it once per lobby visit as a toast plus chat line, and a previous owner's MOTD is never shown. The accessibility Fishing Aid (`/fishaid`, Toggles > Accessibility, default off) needs no hand cast: with the rod out (vanilla fishing key) and the player standing still, it runs at most 20 quick checks with vanilla CastingRay (medium distance straight ahead, then alternating left/right by 20 degrees to 80; then short/medium/long with 10 degree right-to-left pivots) and, if none is water, advises once and waits until the rod is re-equipped or the player casts by hand, or reuses the last hand-cast spot within 2 m; it answers bites after the chosen reaction delay, clicks reel rounds only when vanilla's own zone rule would hit, clicks the last round at the chosen speed, never presses Release (catches are kept), waits with a notice only when no bait is owned (owned bait never runs out with Reusable Consumables), and supplies clicks only on the frame the fishing code reads them. Host Health reports the live lobby as lobby=members/(MaxPlayers-1), matching the game, and PlayerLimitLift's ceiling as pllMax. `/rebind` with no arguments reports all four hotkeys' current bindings; `/rebind <target>` (qolmenu, stylemenu, fly, sweep) starts in-game key capture identical to the QoL menu's Rebind button, cancellable with Esc or `/rebind <target> cancel`; `/rebind <target> <key>` sets it directly; `/rebind reset` or `/rebind <target> reset` restores defaults (Home/Insert/End/F8). No config file edit is ever required for any of the three new rebindable hotkeys or the pre-existing Manual Sweep key. Every candidate key -- from in-game capture or from `/rebind <target> <key>` -- is rejected with a stated reason if it is a fly-movement/typing key (WASD, Space, E, Q, Ctrl, Shift, Alt, Return, Tab, Backspace, Escape) or already bound to another BlueSage hotkey; Mouse and Joystick buttons are never offered; the allowed set is function keys, Home/End/Insert/Delete/Page Up/Page Down, arrow keys, and lock/system keys -- every letter, digit, punctuation, and numpad key is refused because it can be typed into chat or a slash command, and all hotkeys pause while any text box is focused. Saved bindings are repaired on load: typing keys reset to their default, collisions turn the later hotkey off with a notice, and exotic non-typable binds (e.g. Mouse4) are kept. `None` is exempt from the collision check (it means "disabled" on more than one hotkey at once, not a real key fight). Capturing a rebind never stops BlueSage's host-side polling (moderation capability, member-data requests, identity resync). `/welcome` reopens the first-lobby welcome overlay on demand, independent of whether it was already dismissed this version, and independent of the separate chat Welcome Message toggle. `/bsqol` with no arguments (also `/qol`, `/guide`, `/faq`) opens the scrollable cozy guide pop-up; `/bsqol status` and `hosthealth` keep their checks (`diag` was removed with the developer diagnostics in round 4) and `/bsqol commands` prints the text list. `/announce <message>` lets only the current host or a ready Helper write a bounded (160-char, markup-stripped, 10-second rate-limited) heads-up to their own Steam lobby member data; QoL clients show it as a toast plus chat line only when the sender is the current owner or an owner-published Helper, never replay notices older than 120 seconds, and honor the separate Host Announcements toggle. While flying, Alt precision uses FlyPrecisionPercent (default 15%, 5-50) and the chosen FlyRotateButton (default middle mouse; skipped while right mouse already rotates) drives vanilla camera rotation. Extended Camera Zoom (default on) widens scroll zoom to 0.2x-4x the vanilla range walking or flying, never in desk mode; turning it off restores vanilla limits. Scrolling over any BlueSage window never zooms the camera. The game's own 30-minute SweepRoutine raises a toast-only notice; BlueSage's own sweeps do not.

## Chalk, ping, and utility

`/chalk` (`/chalkboard`) with `boards`, `refresh`, `view <index>`, `clear <index>`, `save`, `load`, `list`, `delete`, and `status`; legacy `/chalksave`, `/chalkload` (`/chalkrestore`), `/chalklist`; `/setpingcolor`, `/pingsound`.

Invariant: build 24259292 exposes exactly three scene-local board surfaces: `0` River/Stage, `1` Classroom board A (face A), and `2` Classroom board B (face B). `/chalk boards` or `/chalk refresh` is the source of truth after every lobby or scene change; shared clear/load requires that exact map to remain unchanged and no more than 30 seconds old. Index `3` is never accepted, even if another live surface appears. Local view/save/list/delete/refresh is available to every QoL user. Shared load/clear is Host-direct or authenticated Helper-to-Host only and revalidates authoritative host/server, exact scene/index/fingerprint, current Helper identity, unique lobby membership, version/size, freshness, replay, issuer rate, and cooldown. Every accepted destructive action first writes a recovery snapshot. A failed repaint attempts rollback; unresolved rollback locks every later destructive chalk action until the board/lobby lifecycle changes or the game restarts. Clients with a fresh compatible-client heartbeat replace stale render pixels before the native full-board repaint; vanilla-observer replacement remains an explicit live UAT gate. Every action reports exact board/scene, authority, compatible recipients, snapshot, rollback, and vanilla-observer state. The game stores final board color cells without persistent SteamID/PlayerID stroke ownership, so a ban may prompt `/chalk boards` and the exact clear command but must never infer an offender-owned drawing or auto-clear one. Chalky compatibility stand-down and bounded work remain mandatory.

## Hidden community extras

`/boop` and `/sagewave` are intentionally hidden extras. `/bluedevdebug` is a hidden tombstone (round 4, R7): the developer diagnostics command was removed, so typing it answers locally with a pointer to the QoL menu's Local Audit snapshot instead of broadcasting the text to the lobby. Encoded clue command names remain excluded from public documentation but retain focused contract tests.
